01 / CORTEXJ RUNTIME · 1.0.1

A serious runtime
for Java AI.

Models, artifact formats, native runtimes and hardware constraints should not leak into business logic. CortexJ gives you a stable JVM contract and a plan you can explain before executing.

One model API

Load and use compatible models from local files, Hugging Face, or HTTP-backed repositories through a unified JVM contract.

Smart execution planning

Filter incompatible runtime candidates by format, JVM, hardware, task, and memory. Rank the valid paths deterministically.

Explain every decision

Inspect selected runtimes, rejected candidates, reason codes and fallback behavior instead of debugging mystery execution paths.

Run local or remote

Connect llama.cpp, ONNX Runtime, and OpenAI-compatible endpoints via pluggable runtimes, with explicit offline policies.

Deploy reproducibly

Use pinned model revisions, lockfiles, checksum verification and offline bundles to control what reaches production.

Stay in the JVM

Use the same application-level API across Java 8, 11, 17, 21, and 25 — without a mandatory Python runtime.
